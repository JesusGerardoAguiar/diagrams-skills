# Claude skills

Reusable Claude skills for architecture work.

| Skill | Use it to |
|---|---|
| [c4-figjam-diagrams](skills/c4-figjam-diagrams/SKILL.md) | Create C4 model diagrams (L1 System Context, L2 Containers) on a FigJam board with standard colors, line styles, legends and one section per level. |
| [project-actor-catalog](skills/project-actor-catalog/SKILL.md) | Build or update a project actor catalog in ASD-STE100 style. The catalog feeds the C4 diagrams. |

## Install

- claude.ai: Settings > Capabilities > Skills > upload the skill folder as a zip.
- Claude Code: copy a skill folder into `~/.claude/skills/` (personal) or `.claude/skills/` (one project).
